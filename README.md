# .github

Organization-wide files for [Apex Linux](https://github.com/apex-linux):

*   `profile/README.md`: the organization profile.
*   `CONTRIBUTING.md`, `PULL_REQUEST_TEMPLATE.md`, `SECURITY.md`: defaults
    for every repository that does not define its own.
*   `.github/workflows/conventions.yml`: the shared convention check that
    each repository's `ci.yml` calls as a job.
