# Apex Linux

Apex is a desktop Linux distribution: an image-based Fedora system with a
GNOME desktop built to the Apex design.

*   [`apex`](https://github.com/apex-linux/apex): specification, engineering
    standards and issues. Start here.
*   [`apex-image`](https://github.com/apex-linux/apex-image): the OS image
    and installer media.
*   [`apex-hardware`](https://github.com/apex-linux/apex-hardware): hardware
    rules and acceptance checks.
*   [`apex-desktop`](https://github.com/apex-linux/apex-desktop): design
    tokens, Shell extension, themes and icons.

Repositories named `legacy-*` are an archived earlier attempt, kept for
reference only.
